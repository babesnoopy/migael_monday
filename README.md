# Migael Monday

**นี่คือโปรเจกต์เดียวที่ควรใช้ต่อจากนี้ — เป็นจุดเริ่มต้นใหม่ ไม่ผูกกับโค้ดเก่า (`migael4` / `backup_index`) เลย เพื่อไม่ให้สับสนหรือเผลอแก้ผิดเวอร์ชัน** ของเก่าเก็บไว้อ้างอิงได้ แต่ไม่ต้อง deploy ซ้ำ

ผู้ช่วย AI ของทีม Unformat Studio — LINE bot ที่ใช้ Claude อ่านและเข้าใจข้อความในกลุ่ม ช่วยจด task, นัดมีตติ้ง (พร้อมสร้าง Google Meet), หาไฟล์ใน Drive, เตือนงาน, ตอบคำถามทั่วไป และสรุปให้ทุกวัน

## โครงสร้างไฟล์

- `src/index.js` — จุดเริ่มต้น รับข้อความจาก LINE แล้วตัดสินใจว่าต้องทำอะไร
- `src/brain.js` — ส่วนที่คุยกับ Claude API เพื่อแกะข้อมูลจากข้อความ
- `src/calendar.js` — Google Calendar (สร้าง event, สร้าง Meet link, รองรับหลาย calendar)
- `src/drive.js` — ค้นหาไฟล์/โฟลเดอร์ใน Google Drive
- `src/reports.js` — สร้างรายงานภาพรวม .txt รายวัน (ความคืบหน้าแต่ละโปรเจกต์)
- `src/db.js` — ที่เก็บข้อมูล (sql.js)
- `src/groupState.js` — จำว่าใครอยู่ทีมไหน และ "โหมดฟัง" ของแต่ละกลุ่ม
- `src/scheduler.js` — ตัวส่งข้อความอัตโนมัติ (เช้า/เตือน/เย็น)
- `schema.sql` — โครงสร้างฐานข้อมูลทั้งหมด
- `migael-monday-system-prompt.md` — "นิสัย" และกฎการตัดสินใจของมิเกล
- `oauth-setup.js` — สคริปต์รันครั้งเดียวเพื่อขอสิทธิ์ Google (Calendar + Drive)
- `list-calendars.js` — สคริปต์ช่วยหา calendarId จริงของแต่ละ calendar
- `seed-calendars.js` — เติมข้อมูล UNCOMMU, UNCRLAB, UNFEST26 พร้อม calendar ID จริงที่มีอยู่แล้ว

---

## ⚠️ ก่อนอื่น: จัดการเรื่อง key ที่หลุดจากเวอร์ชันเก่า

ไฟล์ `.env` เวอร์ชันเก่าเคยถูก commit ขึ้น GitHub พร้อม key จริง ให้ทำตามนี้ก่อนเริ่มใช้เวอร์ชันใหม่:

1. **สร้าง key/token ใหม่ทั้งหมด** — LINE channel access token + secret (LINE Developers Console), Anthropic API key (Anthropic Console), Google OAuth client secret (Google Cloud Console)
2. เช็คว่า repo `babesnoopy/migael` เป็น **private**
3. เวอร์ชันนี้มี `.gitignore` กัน `.env` ไว้แล้ว — อย่าลืมใช้ `.env` ใหม่ ไม่ใช่ไฟล์เก่า

---

## ตั้งค่าก่อนใช้งาน

1. คัดลอก `.env.example` เป็น `.env` แล้วกรอกค่า:

```
LINE_CHANNEL_ACCESS_TOKEN=...   # จาก LINE Developers Console (ตัวใหม่)
LINE_CHANNEL_SECRET=...
BABE_USER_ID=...                # LINE userId ของเบ้บ
ANTHROPIC_API_KEY=...           # จาก Anthropic Console (ตัวใหม่)
GOOGLE_CLIENT_ID=...            # จาก Google Cloud Console
GOOGLE_CLIENT_SECRET=...
GOOGLE_REDIRECT_URI=http://localhost:9873/oauth2callback
PORT=3000
```

2. ติดตั้งและขอสิทธิ์ Google (ทำครั้งเดียว รันในเครื่องตัวเอง ไม่ใช่บน Railway):

```
npm install
npm run setup:oauth
```

เปิดลิงก์ที่ขึ้นมา ล็อกอินด้วยบัญชี Google ที่มี calendar/Drive ของทีม แล้ว copy `GOOGLE_REFRESH_TOKEN` ที่ปรากฏในเทอร์มินัลไปใส่ใน `.env` (และใน Railway Variables ตอน deploy จริง)

> หมายเหตุ: token เก่าที่มีอยู่ในไฟล์เก่าเป็น access_token อย่างเดียว ไม่มี refresh_token ทำให้ใช้งานระยะยาวไม่ได้ — ต้องขอใหม่ผ่านสคริปต์นี้

3. เติมข้อมูล project + calendar เข้า DB — เรารู้ calendarId จริงของ UNCOMMU, UNCRLAB, และ UNFEST26 (4 calendar: Content/Meeting/Production/Setup-Dec) อยู่แล้ว รันสคริปต์นี้ทีเดียวได้เลย:

```
npm run seed:calendars
```

ถ้ามี calendar อื่นเพิ่มทีหลังที่ยังไม่รู้ ID ให้ใช้ `npm run setup:calendars` (ต้องรัน `setup:oauth` ก่อน) เพื่อดึงมาเพิ่มเอง

4. ในกลุ่ม LINE ของ UNFEST ให้พิมพ์ `มิเกล กลุ่มนี้คือโปรเจกต์ UNFEST26` ครั้งเดียว (หรือ UNCOMMU / UNCRLAB ตามกลุ่มนั้นๆ) เพื่อผูกกลุ่มกับ project + calendar ที่เพิ่งเติมไป

5. รันจริง:

```
npm start
```

แล้วตั้งค่า Webhook URL ใน LINE Developers Console ให้ชี้มาที่ `https://<your-railway-url>/webhook`

## สิ่งที่ยังไม่สมบูรณ์ในรอบนี้ (ตั้งใจปล่อยไว้ก่อน เอาให้ work ก่อนค่อยเก่งขึ้น)

- **status_update / add_detail_to_open_thread** — logic การอัปเดตสถานะงานและเติมรายละเอียดระหว่างโหมดฟัง ยังเป็นโครงเปล่า
- **onboarding project mapping** — ตอนนี้ setUserTeam ยังไม่ผูกกับ project_id อัตโนมัติ ต้องเลือกเองตอน setup
- **Drive search** ตอนนี้ค้นด้วยชื่อไฟล์/โฟลเดอร์ตรงๆ เท่านั้น ยังไม่ฉลาดเรื่องคำใกล้เคียง

## เพิ่มมิเกลเข้ากลุ่มอื่นๆ

ไม่ต้องตั้งค่าอะไรเพิ่มค่ะ — พอเพิ่มมิเกลเข้ากลุ่มไหน เธอจะทักทายและขอให้ทุกคนแนะนำตัวทันที (ไม่ต้องรอให้มีคนพิมพ์ก่อน) ระบบข้างในรองรับหลายกลุ่มพร้อมกันอยู่แล้วตั้งแต่แรก

**สิ่งที่ต้องทำเพิ่ม 1 อย่าง:** ให้แอดมินกลุ่มพิมพ์ `มิเกล กลุ่มนี้คือโปรเจกต์ [ชื่อโปรเจกต์]` (ชื่อโปรเจกต์ต้องมีอยู่แล้วในตาราง `projects`) — ผูกกลุ่มนี้เข้ากับโปรเจกต์ ทำให้กลุ่มมี calendar ใช้งานได้ทันที (ดึงจาก calendar ที่ผูกกับโปรเจกต์นั้น) ถ้าไม่ผูก กลุ่มจะยังคุยกับมิเกลได้ปกติ แค่สร้าง event ไม่ได้เพราะไม่รู้จะลง calendar ไหน

## จำกัดคนแอดมิเกลส่วนตัว

ตอนนี้มิเกลจะ**ไม่ตอบเต็มรูปแบบ**ให้คนที่แอดเป็นเพื่อนส่วนตัว ยกเว้นอยู่ใน `ALLOWED_PERSONAL_USER_IDS` (ใส่ userId คั่นด้วย comma ใน `.env`) — ถ้าไม่ได้ตั้งไว้ จะ default เป็นแค่ `BABE_USER_ID` คนเดียว ใครแอดนอกเหนือจากนี้จะได้รับข้อความ "สวัสดีค่ะ เราผู้ช่วยเบ้บนะคะ 👋 ตอนนี้ระบบยังไม่ให้คนอื่นใช้ค่ะ"

## เก็บไอเดีย/หัวข้อที่คุยกันไว้ ไม่ให้หายไปในแชท

เวลาทีมคุยเรื่องที่มีความคืบหน้าต่อเนื่อง (เช่น รีวิวสเปคอุปกรณ์, ของที่รอคอนเฟิร์ม) ไม่ใช่แค่ task ธรรมดา — มิเกลจะบันทึกเป็น "topic" แยกไว้ พร้อมสรุปสถานะล่าสุด ลิงก์อ้างอิง และคนที่ถูกแท็ก พอกลับมาถามทีหลัง ("มิเกล เรื่อง X ไปถึงไหนแล้ว") จะสรุปให้ทันทีจากข้อมูลที่มี ไม่ต้องไล่หาในแชทเก่า

ถ้าเรื่องไหนเงียบไปเกิน 3 วัน มิเกลจะแวะถามอัปเดตในกลุ่มเองอัตโนมัติ พร้อมแท็กคนที่เกี่ยวข้อง (ทุกวัน 10:30 น.)

## การแท็กคนใน LINE

ตอนมิเกลเตือนงาน/มีตติ้ง เธอแท็กคนจริงๆ (ขึ้นสีฟ้า แจ้งเตือนไปหาคนนั้นโดยตรง) ไม่ใช่แค่พิมพ์ "@ชื่อ" เฉยๆ — ใช้ LINE Messaging API's mention feature โดยอิงจาก userId จริงที่เก็บไว้ตั้งแต่ตอน onboarding ทำงานอัตโนมัติ ไม่ต้องตั้งค่าเพิ่ม

## รายงานภาพรวมรายวัน (.txt)

นอกจาก recap ข้อความตอนเย็นแล้ว มิเกลจะสร้างไฟล์ `.txt` สรุปความคืบหน้าแต่ละโปรเจกต์ (กี่ % เสร็จ, งานไหนยังค้าง, ใครรับผิดชอบ) แล้วส่งลิงก์**ให้เบ้บส่วนตัวเท่านั้น** — กลุ่มจะได้รับแค่ข้อความสรุป recap ธรรมดา ไม่มีลิงก์ไฟล์ .txt ต่อท้าย ต้องตั้งค่า `PUBLIC_BASE_URL` ใน `.env` เป็น URL ของ Railway ก่อน (เช่น `https://migael-monday.up.railway.app`) ไม่งั้นจะข้ามขั้นตอนนี้ไปเฉยๆ (ยังส่ง recap ข้อความปกติ)
